# Game Stick Lite M8 v6 Toolkit — v2

## Highlights

- English-language release for GitHub/forum sharing.
- DATA03 compatibility report before any modification.
- Supports internal version pattern `M8-YYYYMMDD-release-v6.0` when the expected M8 v6 structure is detected.
- Interactive confirmation before patching.
- Read-only `--check` mode.
- Automatic DATA03 backup.
- External SQLite game database generation.
- Automatic removal of extra dots from ROM filenames.
- Matching cover-image renaming under `roms/img`.
- PS1 `.cue` reference updates after BIN filename changes.
- Filename collision protection.
- Windows launchers that try `python` first and fall back to `py`.
- No third-party Python dependencies.

## Confirmed firmware

`M8-20231122-release-v6.0`

Other M8 v6 revisions should be considered potentially compatible only when the compatibility report passes every check and real-hardware testing succeeds.
